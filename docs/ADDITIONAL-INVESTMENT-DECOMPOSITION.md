# Доинвестирование в актив — план реализации (AD0–AD2)

> Пакет №8 gap-анализа (`GAP-ANALYSIS-PE.md` §1.6): к существующему активу добавляются
> инвестиции (модернизация), увеличивая стоимость и амортизацию. Доп. вложение
> амортизируется **от остаточного срока** актива. **Изменение методики** → бамп
> `ENGINE_VERSION`; пустой список доинвестиций → golden дрейфует только строкой версии.

## 0. Зафиксированные решения (Q1–Q5)

- **Q1. Модель** — `Asset.additional_investments: list[AdditionalInvestment(month, amount)]`.
  Каждое вложение в месяц `m` капитализируется (→ capex/C14 с НДС) и амортизируется
  линейно за **остаточный срок** = `(purchase_month + life_months) − m` (все слои
  заканчиваются вместе с активом).
- **Q2. Слоистая амортизация** — расчёт по слоям: базовая стоимость (слой с началом
  `purchase_month`, ставка `cost/life`) + каждый доп. вложенный слой (начало `m`, ставка
  `amount/остаток`). Амортизация периода = Σ ставок активных слоёв; остаточная стоимость =
  Σ (сумма_слоя − накопленная_аморт_слоя). **Актив без доинвестиций = один базовый слой →
  числа в точности как сейчас** (golden без дрейфа для существующих активов).
- **Q3. Продажа/выбытие**: все слои прекращают амортизацию в месяц продажи (как база);
  выбытие первонач. стоимости (B9) = Σ сумм слоёв, накопленной амортизации (B10) =
  Σ накопленной по слоям; финрезультат — цена − остаточная (Σ по слоям). Земля: слои не
  амортизируются (book = сумма). Переоценка (`revaluation`) — как прежде, поверх суммы
  слоёв (не реверсируется при продаже).
- **Q4. Реюз для этапов/выкупа**: `stage_assets` и выкуп лизинга строят `Asset` без
  доинвестиций — их поведение не меняется. Доп. вложение позже месяца конца жизни актива
  (`m ≥ purchase+life`) не амортизируется (остаток ≤ 0) — капитализируется, но списания
  нет (документировано; ответственность автора модели).
- **Q5. Версия/golden** — бамп `0.9.32`; поле по умолчанию пустое, ни один семпл не задаёт
  → дифф golden = строка версии; рефактор слоёв сохраняет числа существующих активов
  (проверка «непустой не-версионный дифф пуст»). Инвариант B20=B34 держится (property-тест).

## 1. Архитектура

```
calc_core/models/investment.py  # AdditionalInvestment + Asset.additional_investments
calc_core/engine/pipeline.py    # _assets: слоистая амортизация (база + доп. вложения)
frontend                        # доп. вложения в карточке актива (AssetsTab)
```

## 2. Фазы

- [x] **AD0.** Движок: модель + слоистая амортизация в `_assets`; `ENGINE_VERSION=0.9.32` +
  регенерация golden (дифф = версия). Тесты: доп. вложение растит capex/C14, амортизацию
  и остаточную стоимость; амортизация от остаточного срока; продажа после доинвестиции;
  земля не амортизирует доп. вложение; актив без доинвестиций = прежние числа; инвариант.
- [x] **AD1.** API/UI: openapi + `gen:api`, зеркало `model.ts`, блок «Доп. вложения» в
  карточке актива (месяц + сумма, добавление/удаление); проверка сборки.
- [x] **AD2.** Документация: SPEC §9, ROADMAP, GAP-ANALYSIS (1.6), CLAUDE.md, этот чеклист.

## 3. Инварианты

- Актив без `additional_investments` → числа как раньше (golden = строка версии).
- Доинвестиция: capex↑ (C14), амортизация↑ (I17), остаточная стоимость↑ (B11); касса
  оплаты — с НДС; B20=B34 держится (та же машинерия активов; property-тест).

**Статус: завершено** (0.9.32). v2-направления: доинвестиция, продлевающая срок службы
(вместо амортизации от остатка), нелинейные методы амортизации, доинвестиция в стартовые ОС.
