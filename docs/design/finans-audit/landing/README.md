# Лендинг «Финанс» — боевая вёрстка

Семантический HTML5, LESS с БЭМ, ванильный JS. Открывается двойным кликом:
собранный `css/style.css` лежит рядом с исходниками.

## Структура

```
landing/
├── index.html
├── css/style.css          ← собранный, править не нужно
├── less/
│   ├── style.less         ← только @import
│   ├── base/              ← variables, mixins, reset, typography
│   └── blocks/            ← файл на блок БЭМ
├── js/main.js
└── img/                   ← скриншоты экранов продукта
```

## Сборка стилей

```bash
npm i -D less
npx lessc less/style.less css/style.css                  # разработка
npx lessc --source-map less/style.less css/style.css     # с картой исходников
npx lessc --clean-css less/style.less css/style.min.css  # прод
```

## Адаптив

Mobile-first, две точки: `768px` (планшет) и `1280px` (десктоп).
Опорные макеты — 375×812, 768×1024, 1920×1080 (контент 1200px).
Медиазапросы живут внутри блока через миксины `.tablet-up()` / `.desktop-up()`.

## Тема

Тёмная по умолчанию. Переключатель в шапке пишет выбор в `localStorage`
(`finans-theme`), инлайновый скрипт в `<head>` применяет его до первой отрисовки —
без мигания. Палитра — CSS-переменные в `less/base/typography.less`:
`:root` (тёмная) и `[data-theme='light']`.

Золото `#FFCE3A` — заливка на обеих темах; текстовый акцент на светлой
становится `#8A5E0C` (неон как текст на белом даёт ~1.5:1). Продуктовые
акценты — фиолет и зелёный — только на карточках платформ.

## JS

`js/main.js`, шесть независимых инициализаторов: тема, бургер-меню с ловушкой
фокуса и блокировкой скролла, аккордеон FAQ на `aria-expanded`, плавный скролл
по якорям с учётом высоты шапки, валидация формы через Constraint Validation API,
появление секций через `IntersectionObserver`. Узлы ищутся по data-атрибутам.

## Что заменить перед публикацией

- `img/*.png` — сейчас это снимки макетов; нужны экспортные кадры продукта
  в `webp`/`avif` через `<picture>` с `srcset` под три разрешения.
- Тексты тарифов, кейс и контакты — черновые, согласуйте цифры.
- Шрифты подключены с CDN. Для продакшена положите `woff2` в `fonts/`,
  добавьте `@font-face` c `font-display: swap` и `<link rel="preload">`.
- `action` формы: сейчас отправка перехватывается JS и показывает статус.
- Куб — порт брендового объекта из макетов один в один: `less/blocks/cube.less` плюс
  `initCubes()` в `js/main.js`. Шесть текстурированных граней с сеткой, узлами и
  сканирующим лучом, 12 светящихся рёбер, 8 угловых бликов, внутреннее ядро со своим
  каркасом и свечением, орбита из 12 частиц, дыхание, появление и наклон вслед за курсором.
  Вся геометрия в `cqmin` — куб масштабируется вместе с контейнером, размер задаётся
  одной переменной `--cube-size`. Палитра — `--accent-rgb` / `--accent2-rgb`:
  золото для бренда, `.cube--violet` для «Финанс Аудит», `.cube--green` для «Финанс-Элит».
  При `prefers-reduced-motion` орбита и наклон отключаются.
