# Пер-продуктная экономика (BOM/рецептура, материалы, маржа по продуктам) — план

> Пакет №1 gap-анализа (`GAP-ANALYSIS-PE.md` §1.1, §3.2): крупнейший методический разрыв
> с Project Expert. Формат — как ревью (R0–R10) и календарный план (K0–K7): фазы M0–M6,
> каждая = отдельный коммит, golden без дрейфа чисел (модель без BOM инертна).

## 0. Зафиксированные решения (Q1–Q7)

- **Q1. Где живёт рецептура.** В `Product`: список `BomLine(material_id, qty_per_unit)` +
  `piece_wage_per_unit` (сдельная ЗП на единицу). Продукт = сущность со спецификацией, как
  «план производства продукта» PE.
- **Q2. Цена материала.** Скаляр `unit_price` в справочнике `Material`; индексация инфляцией
  прямых издержек (`idx_direct`) — та же, что у суммовых статей. Валютный материал
  (`foreign`) — цена в валюте, без рублёвой индексации (текущее поведение импорта). Ряд цен —
  v2.
- **Q3. Момент потребления.** Расход материала = **производство** (TP продукта, с учётом
  гейта старта из календарного плана), не продажи — как в PE.
- **Q4. Реализация в движке.** Разворачивание BOM в **синтетические `DirectCostLine`**
  (материалы: `amount[t] = Σ_продуктов qty × TP_p[t] × unit_price`; сдельная:
  `wage_per_unit × TP_p[t]`) с параметрами материала (`payment_delay`, `stock_lead`,
  `foreign`) — реюз всей машинерии (деньги C2/C3, запас B3, кредиторка, НДС/импортный НДС,
  курсовые разницы). Приём инъекции — как выкуп лизинга и этапы календаря; инвариант
  сходится машинерией.
- **Q5. Маржа по продуктам.** Аналитический отчёт (`CalcResult.product_margins`), **не**
  меняющий отчётные формы: выручка проданного − BOM-себестоимость проданного (объём продаж ×
  BOM-стоимость единицы в ценах месяца) − сдельная ЗП проданного. Глобальные (суммовые)
  прямые издержки **не распределяются** — показываются отдельной строкой «нераспределённые
  прямые издержки» (принцип ревью: не фейкуем аллокацию). Пул запасов остаётся общим
  (тождество B5 не трогаем).
- **Q6. Совместимость.** Существующие суммовые `DirectCostLine` сосуществуют с BOM (ничего
  не мигрируем); модель без материалов/рецептур ведёт себя в точности как раньше.
- **Q7. Снимок.** `product_margins` попадает в golden-снимок только при непустой рецептуре
  (как `budget`) → существующие golden без дрейфа.

## 1. Модель (calc_core/models/operating.py)

```
Material:                        # справочник в OperatingPlan.materials
  id, name
  unit: str = ""                 # информационно («кг», «шт»)
  unit_price: Decimal            # цена за единицу (валютная — в валюте при foreign)
  payment_delay_months: int = 0  # отсрочка оплаты → кредиторка B23
  stock_lead_months: int = 0     # опережающая закупка → запас сырья B3
  foreign: bool = False          # импорт: курс закупки, импортный НДС

BomLine:
  material_id: str
  qty_per_unit: Decimal          # норма расхода на единицу продукта

Product:                        # расширение существующего
  + bom: list[BomLine] = []
  + piece_wage_per_unit: Decimal = 0
```

## 2. Выход: маржа по продуктам

`CalcResult.product_margins` (`reports/result.py`):

```
ProductMargin: product_id, name, revenue, bom_cost, piece_wages, margin, margin_share
ProductMargins: products: list[ProductMargin], unallocated_direct: Decimal  # Σ суммовых статей
```

Сериализация — при непустых продуктах с рецептурой; схема `ProductMarginsOut` в
`CalcResponse`.

## 3. Ревью v2 (снятие ограничения Q1 из PLAN-REVIEW-ADVISOR)

Пер-продуктные правила категории structure (работают только при наличии BOM):
- `structure.product_negative_margin` [risk]: у продукта BOM-маржа < 0 — «каждая продажа
  в убыток» (исходный пример пользователя, теперь честно по данным);
- `structure.product_thin_margin` [warning]: 0 ≤ маржа продукта < thin_gross_margin.

## 5. Инварианты и совместимость

- Модель без `materials`/`bom` → синтетических строк нет → расчёт байт-в-байт как раньше →
  **golden без дрейфа чисел** (только `engine_version`).
- Синтетические строки проходят тот же путь, что суммовые `DirectCostLine` → сходимость
  баланса гарантирована машинерией; property-тест рандомизирует BOM.
- Маржа — аналитика поверх результата; отчётные формы и налоги не меняются.
