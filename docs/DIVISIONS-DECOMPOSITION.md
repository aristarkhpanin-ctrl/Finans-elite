# Доходы подразделений (структура компании) — план реализации (DV0–DV2)

> Пакет №8 gap-анализа (`GAP-ANALYSIS-PE.md` §4.5): PE ведёт подразделения (бизнес-единицы)
> с разнесением доходов/издержек. У нас структуры компании не было. Реализовано как
> **аналитика поверх пер-продуктной маржи** (пакет №1): группировка продуктов в
> подразделения и свёртка их маржи. **Только новый выход результата — отчётные формы и
> golden-числа не затрагиваются** (пустой список подразделений инертен).

## 0. Зафиксированные решения (Q1–Q4)

- **Q1. Модель структуры.** `Company.divisions: list[Division(id, name)]` — справочник имён;
  отнесение — `Product.division_id` (продукт в ≤1 подразделении, `None` = вне структуры).
  Один источник истины по членству (нет висячих `product_ids`).
- **Q2. Свёртка без фейковой аллокации.** `compute_division_margins(model, product_margins)`
  суммирует **маржу продуктов** (`product_margins`, пакет №1) по `division_id`: выручка,
  BOM-материалы, сдельная ЗП, маржа, доля маржи, число продуктов. В свёртку входят только
  продукты **с рецептурой** (у остальных себестоимость не определена — как и в марже
  продуктов); продукты без подразделения не сворачиваются (видны на уровне продуктов);
  суммовые прямые издержки остаются «нераспределёнными» (в `product_margins`). Висячий
  `division_id` (нет в справочнике) → продукт не сворачивается (нет мусорной группы).
- **Q3. Инертность.** Пустой `divisions` → `division_margins = []` → в снимок/API не
  попадает (как product_margins/participants). Отчётные формы, баланс `B20=B34`, показатели
  и golden-числа не зависят от подразделений (чистая аналитика поверх готовой маржи).
- **Q4. Версия/golden** — бамп `0.9.39` (новый выход результата, как участники/маржа);
  ни один семпл не задаёт подразделения → дифф golden = строка версии.

## 3. Инварианты

- Нет подразделений → `division_margins=[]` → числа и снимок как раньше (golden = версия).
- Свёртка аддитивна к марже продуктов: выручка/маржа подразделения = Σ по его продуктам с
  рецептурой (проверено против `product_margins`).
- Продукты без рецептуры/подразделения и суммовые издержки в свёртку не входят — без
  фейковой аллокации (та же дисциплина, что пер-продуктная маржа).
