# Погодовые ряды инфляции — план реализации (INF0–INF2)

> Пакет №8 gap-анализа (`GAP-ANALYSIS-PE.md` §1.9): инфляция по группам задаётся рядом
> (по годам), а не одной константой. Ядро уже строит накопленный помесячный индекс —
> меняется только источник ставки (год → ставка). **Изменение методики** → бамп
> `ENGINE_VERSION`; пустой ряд → используется скаляр (как сейчас) → golden без дрейфа.

## 0. Зафиксированные решения (Q1–Q5)

- **Q1. Модель** — рядом с существующими скалярами (`inflation_sales/direct/wages/general`)
  добавить опциональные ряды по годам: `inflation_*_series: list[Decimal] = []`. Непустой
  ряд **переопределяет** скаляр; год `k` использует `series[k]`, за пределами ряда — **последнее
  значение** (ставка держится). Пустой ряд → скаляр (обратная совместимость).
- **Q2. Индекс** — `_inflation_index(year_rates, n)` принимает список ставок по годам вместо
  скаляра: месяц `t` растёт по месячной ставке года `t // 12` (`(1+годовая)^(1/12)−1`). Для
  постоянной ставки (ряд `[r]` или скаляр) индекс **совпадает с текущим байт-в-байт** (все
  годы = `r` → та же месячная ставка) → golden без дрейфа.
- **Q3. Резолвер** — `series if series else [scalar]`; `_inflation_index` расширяет ряд
  последним значением для лет за его пределом. Нулевой/пустой → ряд единиц (быстрый путь).
- **Q4. Группа ОС (capex) — v2.** Индексация стоимости активов инфляцией отложена: активы
  бывают синтетическими (этапы календарного плана, выкуп лизинга) — индексация их
  контрактных сумм неоднозначна. Пользователь задаёт стоимость актива на его месяц напрямую.
  Зафиксировано как явное v2-направление (не тихий пропуск).
- **Q5. Версия/golden** — бамп `0.9.33`; ряды по умолчанию пустые, ни один семпл не задаёт →
  скалярный путь без изменений (проверка «непустой не-версионный дифф пуст»).

## 1. Архитектура

```
calc_core/models/project.py   # ProjectSettings: + inflation_*_series (4 ряда)
calc_core/engine/pipeline.py  # _inflation_index(year_rates, n) + резолвер в run_pipeline
frontend                      # ряды по годам в секции «Инфляция» GeneralTab
```

## 2. Фазы

- [x] **INF0.** Движок: поля-ряды, `_inflation_index` по годам + резолвер;
  `ENGINE_VERSION=0.9.33` + регенерация golden (дифф = версия). Тесты: постоянный ряд =
  скаляр (байт-в-байт), меняющийся ряд по годам, расширение последним значением, пустой
  ряд = скаляр, взаимодействие с валютными (не индексируются), инвариант.
- [x] **INF1.** API/UI: openapi + `gen:api`, зеркало `model.ts`, ввод ряда по годам в
  секции «Инфляция» (переключение скаляр/ряд); проверка сборки.
- [x] **INF2.** Документация: SPEC §3, ROADMAP, GAP-ANALYSIS (1.9, ОС-группа → v2),
  CLAUDE.md, этот чеклист.

## 3. Инварианты

- Пустой ряд → скаляр → числа как раньше (golden = строка версии).
- Постоянный ряд ≡ скаляр (тот же индекс). Валютные статьи рублёвой инфляцией не
  индексируются (как сейчас). B20=B34 держится.

**Статус: завершено** (0.9.33). v2-направления: инфляция ОС/capex (индексация стоимости
активов), помесячные ряды (не только погодовые), группа «недвижимость» отдельно от общей.
