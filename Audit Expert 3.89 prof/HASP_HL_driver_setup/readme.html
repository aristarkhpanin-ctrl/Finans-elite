HASP HL Driver GUI Installer: Readme

The list below includes new HASP HL Device Driver features, improvements, issues addressed, and other relevant information.

Upgrade Note

When upgrading the driver, ensure that no running service is using the driver. Although the installation program terminates applications that are accessing the driver, it does not terminate running services. For example, if the HASP License Manager is running as a service, you must stop the service before upgrading the driver.

Version 5.22 (January 2006)

Supported Platforms

Windows x86 and x64

Enhancements

  • Support for Windows Vista x86 and x64 operating systems.
  • Win32 HASP HL Envelope-protected applications that use DataHASP or overlays can now run on Win x64 operating systems.
Note:

By default, the Vista operating system displays a User Account Control message during driver installation. You must click Allow to continue the installation. Alternatively, you can change the default setting from the Control Panel of your Vista operating system.

Limitations

  • To run Win32 HASP HL Envelope-protected applications that use DataHASP or overlays on Windows x64 operating systems, you must install the drivers using a HASP HL installer utility. Drivers installed using Windows Update do not enable DataHASP and overlay functionality for these applications.
  • When using Win32 HASP HL Envelope-protected applications using DataHASP or overlays that run on Windows x64 operating systems, to prevent possible data loss any memory-mapped files must be unmapped by the application.
  • This driver does not support Win32 HASP HL Envelope v.1.11 for .NET Framework 2.0-protected applications that run on Win x64 operating systems.

Known Issues

  • Ref # 5116: When using DataHASP protection on an x64 operating system, with certain anti-virus applications, data may be lost.
  • Ref # 5196: The HASP HL Device Driver Installation program installs the driver for Microsoft 98 and Microsoft ME, although this is not stated in the Welcome screen of the HASP HL Device Driver Installation wizard.
