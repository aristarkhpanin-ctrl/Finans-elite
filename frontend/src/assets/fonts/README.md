# Шрифты в сборке

**Satoshi** (400, 500, 700) — Indian Type Foundry, бесплатная лицензия ITF Free Font
License (https://www.fontshare.com/licenses/itf-ffl): использование в коммерческих
проектах и встраивание в сайты и приложения разрешены; отдельно от продукта файлы не
распространяются.

Лежит в сборке, а не грузится с `api.fontshare.com` (найдено в пакете L, L5): внешний
запрос со **всех** страниц, включая вход и план по ссылке, передавал адрес посетителя
зарубежному сервису до всякого согласия — и политика обработки персональных данных не
могла бы честно сказать, что сторонних получателей у страницы нет. Inter и JetBrains Mono
приходят пакетами `@fontsource/*` (лицензия SIL OFL 1.1) — тоже из сборки.
