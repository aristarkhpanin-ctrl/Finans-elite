  structure, assumptions, divergence), каждая находка — `Finding` с числовым `evidence`.

- Гейт финализации (решение Q4): `POST /projects/{id}/finalize` — risk-находки блокируют до
  `acknowledge`; правка модели (`PUT`) сбрасывает `status` в draft. Методика/решения —
  `docs/PLAN-REVIEW-ADVISOR.md`, `docs/REVIEW-ADVISOR-DECOMPOSITION.md`. UI — вкладка «Ревью плана».

## Автоподбор инвестиций (пакет №8, gap §6) — завершено (I0–I2, 0.9.30)

- `AutoFinancing.invest_surplus`/`invest_annual_rate`: касса выше `min_balance` выметается
  в депозит (симметрично автокредиту). Единый решатель `solve_cash_management` в одном
  проходе ведёт кредит и депозит; при дефиците депозит изымается раньше кредита, при
  профиците сперва гасится кредит. **При `invest_on=False` совпадает с `solve_credit_line`
  байт-в-байт** (equivalence-тест) → кредит-only golden без дрейфа. Депозит реюзает
  машинерию ручных вложений (C8/C9/B6); доход → I20 растит налог → итерация по двум рядам
  (проценты I18 + доход I20). Инъекция инертна при выключенном размещении; бамп 0.9.30,
  golden — только строка версии. Методика — SPEC §19; план — `docs/AUTO-INVEST-DECOMPOSITION.md`.

## Нормирование процентов по ставке ЦБ (пакет №8, gap 2.2) — завершено (N0–N2, 0.9.31)

- `ProjectSettings.cb_refinancing_rate` (0 = выключено) + `interest_norm_multiple`:
  проценты вычитаемы (I18) в пределах `ставка_ЦБ × коэффициент`, сверхнорматив → I24.

## Доинвестирование в актив (пакет №8, gap 1.6) — завершено (AD0–AD2, 0.9.32)

- `Asset.additional_investments: list[AdditionalInvestment(month, amount)]` — модернизация:
  доп. вложение капитализируется (C14 с НДС) и амортизируется от **остаточного срока**
  (`purchase + life − month`). `_assets` переписан на **слоистую амортизацию**: базовый слой
  (`cost/life`) + слой на каждое вложение (`amount/остаток`), все слои заканчиваются вместе
  с активом. Амортизация периода = Σ ставок активных слоёв; остаточная стоимость и выбытие
  при продаже — Σ по слоям; земля слои не амортизирует. **Актив без доинвестиций = один
  базовый слой → числа как прежде** (рефактор проверен: не-версионный дифф golden пуст).
  Бамп 0.9.32; поле пустое по умолчанию. Методика — SPEC §9; план —
  `docs/ADDITIONAL-INVESTMENT-DECOMPOSITION.md`. UI — блок в карточке актива (AssetsTab).

## Погодовые ряды инфляции (пакет №8, gap 1.9) — завершено (INF0–INF2, 0.9.33)

- `ProjectSettings.inflation_*_series` (4 группы): ряды ставок по годам переопределяют

  версии (бамп 0.9.33). Резолвер `_inflation_year_rates`; тот же источник в `margins.py`.
  Инфляция ОС/capex — v2 (синтетические активы делают индексацию контрактных сумм

  UI — таблица «Инфляция по годам» в секции «Инфляция» (GeneralTab).
